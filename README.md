# Telegram Moderation Bot

Бот для модерации чатов: фильтр мата, антиспам, обнаружение ботов.

## Установка

1. `pip install -r requirements.txt`
2. Установите токен в переменную окружения `BOT_TOKEN`
3. `python bot.py`

## Команды

- `/start` – приветствие
- `/info` – статистика
- `/verify <id>` – подтвердить человека (админ)
- `/ban <id>` – заблокировать (админ)
- `/addbot <id>` – добавить ID в чёрный список ботов
